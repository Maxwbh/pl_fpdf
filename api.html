Índice de Utilização da API

Todas as funcionalidades oficiais do PL_FPDF — o que cada uma faz e como usar. Detalhes completos de parâmetros e erros na referência (DOCUMENTATION.md).

01 Ciclo de vida 02 Páginas e posição 03 Fontes e UTF-8 04 Escrita de texto 05 Cores e desenho 06 Imagens e links 07 Cabeçalho/rodapé 08 QR e barras 09 Metadados 10 Saída 11 Manipular PDF 12 Overlays 13 Merge / Split 14 Segurança

Como passar parâmetros: toda API aceita notação posicional (Cell(0, 10, 'Olá', '1', 1, 'C')) ou nomeada (Cell(pw => 0, ph => 10, ptxt => 'Olá', palign => 'C')) — a nomeada é a recomendada. Parâmetros com default podem ser omitidos; medidas usam a unidade do Init; cores são RGB 0–255; faixas de páginas aceitam 'ALL' ou '1,3-5,21-'; opções extras viajam em JSON_OBJECT_T.

01 Ciclo de vida

Todo documento começa com Init; o estado vive na sessão (package-only).

APIO que faz
Init(orient, unit, format, encoding)Inicia documento: 'P'/'L' · mm/cm/pt/in · A3/A4/A5/Letter/Legal · UTF-8
ResetZera o estado e libera CLOBs temporários
IsInitializedTRUE se há documento em andamento
co_versionConstante com a versão instalada
hello.sql
DECLARE l_pdf BLOB;
BEGIN
  PL_FPDF.Init(
    p_orientation => 'P',     -- 'P' retrato | 'L' paisagem
    p_unit        => 'mm',    -- 'mm' | 'cm' | 'pt' | 'in'
    p_format      => 'A4');   -- 'A4' | 'A3' | 'A5' | 'Letter' | 'Legal'
  PL_FPDF.AddPage();
  PL_FPDF.SetFont('Arial', 'B', 16);  -- família, estilo ''/B/I/BI/U, tamanho pt
  PL_FPDF.Cell(0, 10, 'Olá, Mundo!', '0', 1, 'C');
  l_pdf := PL_FPDF.OutputBlob();
END;

02 Páginas e posicionamento

APIO que faz
AddPage(orient, format, rotation)Nova página; NULL herda do Init; rotação 0/90/180/270
SetPage(n) · GetCurrentPage · PageNoVoltar a uma página existente · página ativa · nº corrente
SetMargins(l,t,r) e variantesMargens (SetLeftMargin / SetTopMargin / SetRightMargin)
SetAutoPageBreak(auto, margem)Quebra automática ao atingir a margem inferior
Ln(h) · GetX/SetX · GetY/SetY · SetXYControle do cursor de escrita
paginas.sql
PL_FPDF.SetMargins(left => 20, top => 15, right => 20);  -- right omitido = igual à esquerda
PL_FPDF.SetAutoPageBreak(pauto => TRUE, pMargin => 15);    -- quebra a 15mm do fim
PL_FPDF.AddPage(p_orientation => 'L');                     -- só o que muda; resto herda do Init
PL_FPDF.SetXY(x => 20, y => 40);                           -- cursor na unidade do documento

04 Escrita de texto

APIO que faz
Cell(w,h,txt,borda,ln,alinh,fill,link)Bloco retangular — a API mais usada
MultiCell(w,h,txt,borda,alinh,fill)Parágrafo com quebra automática (function retorna nº de linhas)
Write(h, txt, link)Texto fluido inline (misture fontes no meio da frase)
Text(x, y, txt)Posição absoluta, sem mover o cursor
CellRotated(...) · WriteRotated(...)Texto rotacionado 0/90/180/270
GetStringWidth(txt) · SetLineSpacingMedição para centralizar · espaçamento entre linhas
cell_parametros.sql
PL_FPDF.Cell(
  pw      => 0,        -- largura; 0 = até a margem direita
  ph      => 10,       -- altura da célula
  ptxt    => 'Total: R$ 1.234,56',
  pborder => 'LTB',    -- '0' | '1' | combinação de L,T,R,B
  pln     => 1,        -- 0 cursor à direita | 1 próxima linha | 2 abaixo
  palign  => 'R',      -- 'L' | 'C' | 'R'
  pfill   => 1,        -- 1 = fundo com a cor de SetFillColor
  plink   => '');      -- URL ou link interno (AddLink)

l_linhas := PL_FPDF.MultiCell(0, 6, l_paragrafo, '1', 'J');  -- 'J' justificado; retorna nº de linhas
PL_FPDF.CellRotated(40, 10, 'VERTICAL', p_rotation => 90);   -- 0/90/180/270

05 Cores e desenho

APIO que faz
SetDrawColor / SetFillColor / SetTextColor (r,g,b)Cores RGB 0–255 de contorno, preenchimento e texto
SetLineWidth · SetDash · SetLineDashPatternEspessura e tracejado
Line(x1,y1,x2,y2) · Rect(x,y,w,h,estilo)Linha · retângulo ('' contorno, 'F' cheio, 'DF' ambos)
Poly(pontos, fechar, estilo) · Triangle(...)Polígonos e triângulos
desenho.sql
PL_FPDF.SetDrawColor(r => 200, g => 0, b => 0);   -- RGB 0-255; só r = tom de cinza
PL_FPDF.SetFillColor(240, 240, 240);
PL_FPDF.SetLineWidth(0.5);                          -- na unidade do documento
PL_FPDF.Rect(px => 10, py => 40, pw => 60, ph => 25, pstyle => 'DF');  -- '' contorno | 'F' cheio | 'DF' ambos
PL_FPDF.SetLineDashPattern('[3 2] 0');              -- 3 on, 2 off (pontos PDF)

07 Cabeçalho e rodapé automáticos

Registre procedures suas para executarem a cada página, com parâmetros.

APIO que faz
SetHeaderProc(proc, params)Procedure chamada no topo de cada página
SetFooterProc(proc, params)Procedure chamada no rodapé
SetAliasNbPages('{nb}')Placeholder do total de páginas ("Página 2/{nb}")
rodape.sql
-- procedure sua, chamada a cada página:
PL_FPDF.SetFooterProc(footerprocname => 'meu_pkg.meu_footer');
PL_FPDF.SetHeaderProc(
  headerprocname => 'meu_pkg.meu_header',
  paramTable     => tv4000a('Relatório Mensal', 'Ago/2026'));  -- parâmetros da sua proc
PL_FPDF.SetAliasNbPages('{nb}');  -- use '{nb}' no texto = total de páginas

08 QR Code e código de barras

APIO que faz
AddQRCode(x, y, size, dados, formato, correção)Formatos TEXT, URL, PIX, VCARD, WIFI, EMAIL · correção L/M/Q/H
AddBarcode(x, y, w, h, código, tipo, texto)CODE128, CODE39, EAN13, EAN8, ITF14

PIX com payload EMV completo e Boleto FEBRABAN prontos para uso estão na extensão brazilian-payments.

qr_barras.sql
PL_FPDF.AddQRCode(
  p_x => 150, p_y => 20, p_size => 40,   -- posição e lado (unidade do doc)
  p_data             => 'https://msbrasil.inf.br',
  p_format           => 'URL',          -- TEXT | URL | PIX | VCARD | WIFI | EMAIL
  p_error_correction => 'M');           -- L 7% | M 15% | Q 25% | H 30%

PL_FPDF.AddBarcode(
  p_x => 30, p_y => 70, p_width => 150, p_height => 20,
  p_code      => '7891234567895',
  p_type      => 'EAN13',               -- CODE128 | CODE39 | EAN13 | EAN8 | ITF14
  p_show_text => TRUE);                 -- número legível abaixo das barras

11 Manipulação de PDF existente

Fluxo: LoadPDF → inspecionar/modificar → OutputModifiedPDF.

APIO que faz
LoadPDF(blob)Carrega e interpreta um PDF existente
GetPageCount · GetPDFInfoTotal de páginas · metadados/versão (JSON)
RotatePage(n, graus) · RemovePage(n)Rotação 0/90/180/270 · remoção de página
AddWatermark(texto, opacidade, rotação, páginas, fonte, tam, cor)Marca d'água em 'ALL' ou '1,3-5'
GetWatermarks · GetActivePageCount · IsPageRemoved · IsPDFModifiedConsultas de estado (JSON)
OutputModifiedPDF → BLOB · ClearPDFCacheGera o PDF final · libera memória
editar.sql
PL_FPDF.LoadPDF(l_pdf);
PL_FPDF.RotatePage(p_page_number => 1, p_rotation => 90);  -- 0/90/180/270
PL_FPDF.AddWatermark(
  p_text     => 'CONFIDENCIAL',
  p_opacity  => 0.3,      -- 0.0 transparente … 1.0 opaco
  p_rotation => 45,       -- diagonal clássica
  p_pages    => 'ALL',    -- ou '1,3-5'
  p_size     => 48,       -- pontos
  p_color    => 'gray');
PL_FPDF.RemovePage(3);
l_pdf := PL_FPDF.OutputModifiedPDF();

12 Overlays — conteúdo sobre PDF existente

Carimbos, logos e assinaturas em coordenadas exatas (pontos PDF; Y de baixo para cima).

APIO que faz
OverlayText(página, texto, x, y, opções)Opções JSON: font, fontSize, color, opacity, rotation, align, bold, zOrder
OverlayImage(página, blob, x, y, w, h, opções)JPEG/PNG; opacity, rotation, maintainAspect, scaleToFit
GetOverlays(página) · RemoveOverlay(id) · ClearOverlays(página)Gestão das sobreposições
overlay.sql
PL_FPDF.OverlayText(
  p_page_number => 1,
  p_text        => 'APROVADO',
  p_x => 400, p_y => 700,               -- pontos PDF; Y conta de baixo para cima
  p_options     => JSON_OBJECT_T('{
    "fontSize":24, "color":"FF0000", "opacity":0.8,
    "rotation":0, "align":"left", "bold":true }'));

PL_FPDF.OverlayImage(
  p_page_number => 1, p_image_blob => l_logo,
  p_x => 450, p_y => 750,
  p_width => 100, p_height => NULL,      -- NULL = proporcional / original
  p_options => JSON_OBJECT_T('{"opacity":0.9,"maintainAspect":true}'));

13 Multi-PDF: merge, split e extração

APIO que faz
LoadPDFWithID(blob, id) · UnloadPDF(id) · GetLoadedPDFsVários PDFs em memória, cada um com ID
MergePDFs(ids JSON) → BLOBMescla na ordem do array
SplitPDF(id, ranges JSON) → JSONDivide por intervalos ("1-10", "11-20", "21-")

PL_FPDF.LoadPDFWithID(l_capa, 'capa');

l_final := PL_FPDF.MergePDFs(JSON_ARRAY_T('["capa","corpo"]'));

14 Segurança e criptografia (v3.2)

APIO que faz
EncryptPDF(pdf, senha_user, senha_owner, permissões, algoritmo)Protege um BLOB pronto — 'RC4-128' ou 'RC4-40'
DecryptPDF(pdf, senha)Remove a proteção
IsEncrypted(pdf) · GetSecurityInfo(pdf)Verifica e inspeciona (algoritmo, chave, permissões)
SetEncryption(...) · SetPermissions(...)Criptografia e permissões de um documento novo, antes do OutputBlob
SetPDFVersion('1.7') · GetPDFVersionVersão do arquivo gerado
proteger.sql
l_perms := JSON_OBJECT_T();
l_perms.put('print', TRUE);          -- também: modify, copy, annotate,
l_perms.put('copy',  FALSE);         --   fill_forms, extract, assemble, print_high

l_seguro := PL_FPDF.EncryptPDF(
  p_pdf            => l_pdf,
  p_user_password  => 'senhaLeitura',   -- pedida ao abrir
  p_owner_password => 'senhaAdmin',     -- NULL = igual à de usuário
  p_permissions    => l_perms,
  p_encryption     => 'RC4-128');      -- ou 'RC4-40' (legado)

AES-256 e assinatura digital estão no roadmap.
