PL_FPDF

Geração e manipulação de PDF 100% em PL/SQL, executando diretamente dentro do Oracle Database — sem Java, sem middleware, sem dependências externas.

Ver no GitHub Como instalar Releases

📌 Este projeto é um fork mantido ativamente de Pilooz/pl_fpdf — o porte PL/SQL original do FPDF (PHP) — atualizado por @maxwbh para Oracle 19c/23c, com manipulação de PDF, criptografia RC4 e extensão PIX/Boleto.

Por que usar

Roda dentro do banco

Sem servidor de aplicação, sem Java Stored Procedures — gere o PDF na própria trigger, job ou API PL/SQL.

Manipula PDFs existentes

Carregar, rotacionar, marcar d'água, mesclar e dividir arquivos PDF já prontos.

Segurança RC4

Criptografia com senha de usuário/proprietário e controle de permissões (imprimir, copiar, editar).

PIX e Boleto

Extensão opcional para gerar QR Code PIX (EMV) e Boleto Bancário (padrão FEBRABAN).

Zero dependências

Sem OWA, sem OrdImage, sem libs de terceiros. Apenas dois arquivos: .pks + .pkb.

Open source (MIT)

Código aberto, com CI automatizado e histórico de versões documentado.

Exemplo rápido

DECLARE
  l_pdf BLOB;
BEGIN
  PL_FPDF.Init('P', 'mm', 'A4');
  PL_FPDF.AddPage();
  PL_FPDF.SetFont('Arial', 'B', 16);
  PL_FPDF.Cell(0, 10, 'Olá, Mundo!', '0', 1, 'C');
  l_pdf := PL_FPDF.Output_Blob();
END;
