API Usage Index

Every official PL_FPDF feature — what each one does and how to call it. Full parameter and error detail in the API reference.

01 Life cycle 02 Pages and position 03 Fonts and UTF-8 04 Writing text 05 Colours and drawing 06 Images and links 07 Header/footer 08 QR and barcodes 09 Metadata 10 Output 11 Editing PDF 12 Overlays 13 Merge / Split 14 Security

How to pass parameters: every API accepts positional notation (Cell(0, 10, 'Hello', '1', 1, 'C')) or named (Cell(pw => 0, ph => 10, ptxt => 'Hello', palign => 'C')) — named is the recommended one. Parameters with a default may be omitted; measurements use the unit given to Init; colours are RGB 0–255; page ranges accept 'ALL' or '1,3-5,21-'; extra options travel in a JSON_OBJECT_T.

01 Life cycle

Every document starts with Init; the state lives in the session (package-only).

APIWhat it does
Init(orient, unit, format, encoding)Starts a document: 'P'/'L' · mm/cm/pt/in · A3/A4/A5/Letter/Legal · UTF-8
ResetClears the state and frees temporary CLOBs
IsInitializedTRUE if a document is in progress
co_versionConstant holding the installed version
hello.sql
DECLARE l_pdf BLOB;
BEGIN
  PL_FPDF.Init(
    p_orientation => 'P',     -- 'P' portrait | 'L' landscape
    p_unit        => 'mm',    -- 'mm' | 'cm' | 'pt' | 'in'
    p_format      => 'A4');   -- 'A4' | 'A3' | 'A5' | 'Letter' | 'Legal'
  PL_FPDF.AddPage();
  PL_FPDF.SetFont('Arial', 'B', 16);  -- family, style ''/B/I/BI/U, size in pt
  PL_FPDF.Cell(0, 10, 'Hello, World!', '0', 1, 'C');
  l_pdf := PL_FPDF.OutputBlob();
END;

02 Pages and positioning

APIWhat it does
AddPage(orient, format, rotation)New page; NULL inherits from Init; rotation 0/90/180/270
SetPage(n) · GetCurrentPage · PageNoGo back to an existing page · active page · current number
SetMargins(l,t,r) and variantsMargins (SetLeftMargin / SetTopMargin / SetRightMargin)

Ln(h) · GetX/SetX · GetY/SetY · SetXYControl of the writing cursor
pages.sql
PL_FPDF.SetMargins(left => 20, top => 15, right => 20);  -- right omitted = same as left
PL_FPDF.SetAutoPageBreak(pauto => TRUE, pMargin => 15);    -- breaks 15mm from the bottom
PL_FPDF.AddPage(p_orientation => 'L');                     -- only what changes; the rest inherits from Init
PL_FPDF.SetXY(x => 20, y => 40);                           -- cursor in the document unit

04 Writing text

APIWhat it does
Cell(w,h,txt,border,ln,align,fill,link)Rectangular block — the most used API
MultiCell(w,h,txt,border,align,fill)Paragraph with automatic wrapping (the function returns the line count)
Write(h, txt, link)Inline flowing text (mix fonts mid-sentence)
Text(x, y, txt)Absolute position, without moving the cursor
CellRotated(...) · WriteRotated(...)Text rotated 0/90/180/270
GetStringWidth(txt) · SetLineSpacingMeasuring in order to centre · line spacing
cell_parameters.sql
PL_FPDF.Cell(
  pw      => 0,        -- width; 0 = up to the right margin
  ph      => 10,       -- cell height
  ptxt    => 'Total: 1,234.56',
  pborder => 'LTB',    -- '0' | '1' | any combination of L,T,R,B
  pln     => 1,        -- 0 cursor to the right | 1 next line | 2 below
  palign  => 'R',      -- 'L' | 'C' | 'R'
  pfill   => 1,        -- 1 = background in the SetFillColor colour
  plink   => '');      -- URL or internal link (AddLink)

l_lines := PL_FPDF.MultiCell(0, 6, l_paragraph, '1', 'J');  -- 'J' justified; returns the line count
PL_FPDF.CellRotated(40, 10, 'VERTICAL', p_rotation => 90);   -- 0/90/180/270

07 Automatic header and footer

Register procedures of your own to run on every page, with parameters.

APIWhat it does
SetHeaderProc(proc, params)Procedure called at the top of every page
SetFooterProc(proc, params)Procedure called in the footer
SetAliasNbPages('{nb}')Placeholder for the page total ("Page 2/{nb}")
footer.sql
-- a procedure of yours, called on every page:
PL_FPDF.SetFooterProc(footerprocname => 'my_pkg.my_footer');
-- with parameters: tv4000a is an associative array indexed by the parameter NAME
--   l_p PL_FPDF.tv4000a;  (there is no tv4000a(...) constructor)
l_p('p_title')  := 'Monthly Report';
l_p('p_period') := 'Aug/2026';
PL_FPDF.SetHeaderProc(
  headerprocname => 'my_pkg.my_header',
  paramTable     => l_p);
PL_FPDF.SetAliasNbPages('{nb}');  -- use '{nb}' in the text = total pages

08 QR Code and barcode

APIWhat it does
AddQRCode(x, y, size, data, format, correction)Formats TEXT, URL, PIX, VCARD, WIFI, EMAIL · correction L/M/Q/H
AddBarcode(x, y, w, h, code, type, text)CODE128, CODE39, EAN13, EAN8, ITF14

PIX with a full EMV payload and FEBRABAN Boleto, ready to use, live in the brazilian-payments extension — both are Brazilian payment standards.

qr_barcode.sql
PL_FPDF.AddQRCode(
  p_x => 150, p_y => 20, p_size => 40,   -- position and side (document unit)
  p_data             => 'https://msbrasil.inf.br',
  p_format           => 'URL',          -- TEXT | URL | PIX | VCARD | WIFI | EMAIL
  p_error_correction => 'M');           -- L 7% | M 15% | Q 25% | H 30%

PL_FPDF.AddBarcode(
  p_x => 30, p_y => 70, p_width => 150, p_height => 20,
  p_code      => '7891234567895',
  p_type      => 'EAN13',               -- CODE128 | CODE39 | EAN13 | EAN8 | ITF14
  p_show_text => TRUE);                 -- human-readable number below the bars

11 Editing an existing PDF

The flow: LoadPDF → inspect/modify → OutputModifiedPDF.

APIWhat it does
LoadPDF(blob)Loads and parses an existing PDF
GetPageCount · GetPDFInfoPage total · metadata/version (JSON)
RotatePage(n, degrees) · RemovePage(n)Rotation 0/90/180/270 · page removal
AddWatermark(text, opacity, rotation, pages, font, size, colour)Watermark on 'ALL' or '1,3-5'
GetWatermarks · GetActivePageCount · IsPageRemoved · IsPDFModifiedState queries (JSON)
OutputModifiedPDF → BLOB · ClearPDFCacheProduces the final PDF · frees memory
edit.sql
PL_FPDF.LoadPDF(l_pdf);
PL_FPDF.RotatePage(p_page_number => 1, p_rotation => 90);  -- 0/90/180/270
PL_FPDF.AddWatermark(
  p_text     => 'CONFIDENTIAL',
  p_opacity  => 0.3,      -- 0.0 transparent … 1.0 opaque
  p_rotation => 45,       -- the classic diagonal
  p_pages    => 'ALL',    -- or '1,3-5'
  p_size     => 48,       -- points
  p_color    => 'gray');
PL_FPDF.RemovePage(3);
l_pdf := PL_FPDF.OutputModifiedPDF();

14 Security and encryption (v3.2)

APIWhat it does
EncryptPDF(pdf, user_password, owner_password, permissions, algorithm)Protects a finished BLOB — 'AES-256', 'AES-128', 'RC4-128' or 'RC4-40'
DecryptPDF(pdf, password)Removes the protection
IsEncrypted(pdf) · GetSecurityInfo(pdf)Checks and inspects (algorithm, key, permissions)
SetEncryption(...) · SetPermissions(...)Encryption and permissions for a new document, before OutputBlob
SetPDFVersion('1.7') · GetPDFVersionVersion of the generated file
protect.sql
l_perms := JSON_OBJECT_T();
l_perms.put('print', TRUE);          -- also: modify, copy, annotate,
l_perms.put('copy',  FALSE);         --   fill_forms, extract, assemble, print_high

l_seguro := PL_FPDF.EncryptPDF(
  p_pdf            => l_pdf,
  p_user_password  => 'readPassword',   -- asked for on opening
  p_owner_password => 'adminPassword',  -- NULL = same as the user one
  p_permissions    => l_perms,
  p_encryption     => 'AES-256');      -- or 'AES-128', 'RC4-128', 'RC4-40'

A password is not a signature. The encryption above protects the file (who opens it, who prints it, who copies from it) — it does not attest authorship nor detect tampering. Digital signatures (PAdES, ICP-Brasil certificates) do not exist in the library yet.
