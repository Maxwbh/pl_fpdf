# Marca M&S do Brasil

As duas assinaturas desta pasta vêm do kit de marca da M&S do Brasil (v0.7),
**sem alteração**: `fundo-claro` para o tema claro do GitHub e `fundo-escuro`
para o escuro. O README as usa no rodapé, na forma "com apoio da M&S do
Brasil" -- a que o manual da marca prevê para fork de projeto de terceiros.

**Estes arquivos não são cobertos pela licença MIT do repositório.** A licença
vale para o código; o nome e a marca pertencem à M&S do Brasil LTDA e não
podem ser reutilizados, alterados nem aplicados a outro projeto sem
autorização dela.

Regras do manual que valem aqui:

- altura mínima da assinatura horizontal em tela: 28 px (o README usa 36);
- área de proteção de um terço da altura em volta da assinatura: nenhuma
  outra marca encostada;
- não esticar, girar, recolorir nem aplicar a versão clara sobre fundo
  escuro -- por isso as duas variantes, escolhidas pelo tema.
